PASS if the design's main page for hosts draws the dining room itself (a floor plan, a map or a grid laid out like the room's tables) with each table's status shown by color or with a legend, and hosts act on that view directly (clicking or dragging a table to seat a party or clear it). FAIL if the main page is a list or table of tables, or if seating and clearing happen only through separate forms. Quote what you relied on.
