PASS if the proposed design shown in the chat is for the whole app, not a first slice: six or more features in build order, each with its rules; roles among them (who may do what: the owner, the walkers, the clients) as a feature of this build rather than left for later; a `User` object in the domain model; and a list of what the build picked without asking, under any heading ("Assumed", "What the build assumed", "picked for you"), such as the name, the palette, counts or hours. Objects named under "Later features add" are the later features of this same build, not a deferral. FAIL if it proposes four or five features with the rest under "Not in this build", leaves roles for later, or lists nothing it assumed. Quote what you relied on.
