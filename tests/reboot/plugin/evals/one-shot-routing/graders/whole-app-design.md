PASS if the proposed design shown in the chat is for the whole app, not a first slice: six or more features in build order, each with its rules; roles among them (who may do what: the owner, the walkers, the clients) as a feature of this build rather than left for later; a `User` object in the domain model; and an Assumed section that lists what the build picked without asking (such as the name, the accent, features added beyond the prompt). FAIL if it proposes four or five features with the rest under "Not in this build", leaves roles for later, or has no Assumed list. Quote what you relied on.
